# 知识点

## 1. 网络与互联网

**网络（Network）**：一群设备连接起来形成网络。  
**互联网（Internet）**：很多网络再互相连接起来，形成“网络的网络”。

```text
手机 ─┐
电脑 ─┼─ 路由器
平板 ─┘
```

```text
网络A ─┐
网络B ─┼─ 互相连接 → 互联网
网络C ─┘
```

与网络直接相连的计算机称为**主机（Host）**，也叫**端系统**。

## 2. 互联网的发展

**第一阶段：1969**

ARPANET（阿帕网），最初是一个较小的分组交换网络。

**第二阶段：1985**

NSFNET，形成三级结构：

```text
主干网 → 地区网 → 校园网 / 企业网
```

**第三阶段：1993**

逐渐形成多层次 ISP 结构。  
用户通过 ISP 接入互联网，不同 ISP 之间再相互连接。

**ISP：Internet Service Provider，互联网服务提供商。**

例如：中国移动、中国电信、中国联通等。

## 3. 互联网的组成

**边缘部分**

由所有连接到互联网的主机（端系统）组成。  
用户直接使用这些主机进行通信和资源共享。

**核心部分**

由大量网络以及连接这些网络的路由器组成。  
作用：为边缘部分提供**连通性和交换**。

## 4. 传输数据的 3 种交换方式

**电路交换**

类似打电话：

```text
建立连接 → 通信 → 释放连接
```

通信时一直占着一条线路，就算暂时没传数据也占资源，所以资源利用率低。

**报文交换**

整个报文一起传。  
每到一个中间节点，都要先把**整个报文收完并存下来**，再转发到下一个节点。  
优点是不需要提前占一条线路，缺点是报文大时等待久、占存储空间大。

**分组交换**

把一个大报文切成很多小分组，每个分组单独存储转发。  
路由器收到一个完整分组就可以继续转发，不用等整个报文收完。  
多个用户还能共享链路，互联网主要使用分组交换。

**3 种方式区别**

```text
电路交换：先占路，再传
报文交换：整个大报文收完，再传
分组交换：切成小块，一个分组一个分组传
```

## 5. 计算机网络的分类

**按分布范围**

- 广域网：范围很大，可以跨地区、国家。
- 城域网：大致一个城市范围。
- 局域网：范围较小，例如学校、公司内部。
- 个人区域网：个人身边很小的范围。

```text
个人区域网 < 局域网 < 城域网 < 广域网
```

**按使用者**

- 公用网：给公众使用。
- 专用网：某个单位、组织自己使用。

**按交换技术**

- 电路交换
- 报文交换
- 分组交换

**按拓扑结构**

- 总线型：大家接在一条主线上。
- 星型：所有设备连到一个中心。
- 环型：设备首尾相连形成一个环。
- 网状型：节点之间有很多连接，像一张网。

## 6. 计算机网络性能

**速率**

单位时间传输的数据量，单位 `b/s`。

```text
1 kb/s = 10^3 b/s
1 Mb/s = 10^6 b/s
1 Gb/s = 10^9 b/s
1 B = 8 bit
1 KB = 1024 B
```

**带宽**

链路所能达到的最高数据传输速率，单位也是 `b/s`。

**吞吐量**

单位时间内实际传输的数据量，一般小于等于带宽。

**时延**

时延分为：

```text
发送时延
传播时延
处理时延
排队时延
```

公式：

```text
发送时延 = 数据长度 / 发送速率

传播时延 = 链路长度 / 传播速度

总时延 = 发送时延 + 传播时延 + 处理时延 + 排队时延

时延带宽积 = 传播时延 × 带宽
```

时延带宽积表示链路中正在传播的数据量。

**RTT**

RTT 是往返时间。  
从发送方发送数据开始，到收到对方返回信息所经历的时间。

**利用率**

网络或链路被使用的程度。  
利用率太高时，排队时延会明显增大。

**单位注意**

链路长度通常用 `m`。  
光纤中约 `2×10^8 m/s` 指的是**传播速度**，不是发送速率。

```text
发送速率：看 b/s
传播速度：看 m/s
```

注意区分 `bit` 和 `Byte`：

```text
1 B = 8 b

b/s：表示速率

B、KB、MB、GB：表示存储容量
```

网络速率中的 `k、M、G` 按 `10^3` 进位。  
存储容量中的 `KB、MB、GB` 通常按 `1024` 进位。

## 7. 计算机网络体系结构

**协议**

通信双方必须共同遵守的规则，主要包括**语法、语义和同步**。

- 语法：数据长什么样。
- 语义：这些内容是什么意思。
- 同步：什么时候做什么，先后顺序怎样。

**服务**

下层为紧邻的上层提供服务，上层使用下层提供的服务。  
同一层通信双方遵守相应协议。

常见有 3 种体系结构：

```text
OSI 七层参考模型
TCP/IP 四层模型
五层参考模型
```

**OSI 七层参考模型**

```text
应用层
表示层
会话层
传输层
网络层
数据链路层
物理层
```

从下往上记：

```text
物理层 → 数据链路层 → 网络层 → 传输层 → 会话层 → 表示层 → 应用层
```

OSI 是 ISO 提出的法律上的国际标准，但实际互联网没有采用它作为主要体系结构。

**TCP/IP 四层模型**

```text
应用层
运输层
网际层
网络接口层
```

TCP/IP 在实际互联网中广泛使用，是**事实上的国际标准**。

**五层参考模型**

```text
应用层
运输层
网络层
数据链路层
物理层
```

主要用于教学。

可以理解成：

```text
TCP/IP 的网络接口层
        ↓
拆成
        ↓
数据链路层 + 物理层
```

同时：

```text
OSI 的应用层 + 表示层 + 会话层
                ↓
             应用层
```

三种模型主要区别是**层数不同，以及部分层的合并方式不同**，核心分层思想相同。

**应用层**

直接为用户和应用程序提供网络服务。  
常见协议：`HTTP、FTP、SMTP、DNS`。  
协议数据单元一般叫**报文**。

**运输层**

负责两个主机中**进程与进程之间**的通信，可以提供可靠传输、流量控制等。  
常见协议：`TCP、UDP`。  
协议数据单元通常叫**报文段（TCP）**或**用户数据报（UDP）**。

**网络层**

负责把分组从源主机送到目的主机，主要进行**路由选择和分组转发**。  
常见协议：`IP、ICMP、OSPF` 等。  
协议数据单元叫 **IP 数据报 / 分组**。

**数据链路层**

负责把网络层传下来的数据组装成**帧**，在相邻节点之间传输。  
协议数据单元叫**帧**。

**物理层**

负责在实际传输介质上传输 `0` 和 `1` 的比特流。  
协议数据单元叫**比特**。

**数据传输过程**

```text
发送端：应用层 → 运输层 → 网络层 → 数据链路层 → 物理层
                       逐层封装 ↓

接收端：应用层 ← 运输层 ← 网络层 ← 数据链路层 ← 物理层
                       逐层拆封 ↑
```
