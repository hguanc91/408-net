# 知识点

1. 网络与互联网
网络（Network）：一群设备连接起来形成网络。
互联网（Internet）：很多网络再互相连接起来，形成“网络的网络”。
手机 ─┐
电脑 ─┼─ 路由器
平板 ─┘
网络A ─┐
网络B ─┼─ 互相连接 → 互联网
网络C ─┘
与网络直接相连的计算机称为主机（Host），也叫端系统。

2. 互联网的发展
第一阶段：1969
ARPANET（阿帕网）
最初是一个较小的分组交换网络。
第二阶段：1985
NSFNET
形成三级结构：
主干网 → 地区网 → 校园网/企业网。
第三阶段：1993
逐渐形成多层次 ISP 结构。
用户通过 ISP 接入互联网，不同 ISP 之间再相互连接。
ISP：Internet Service Provider，互联网服务提供商。
例如：中国移动、中国电信、中国联通等。

3. 互联网的组成
（1）边缘部分
由所有连接到互联网的主机（端系统）组成。
用户直接使用这些主机进行通信和资源共享。
（2）核心部分
由大量网络以及连接这些网络的路由器组成。
作用：为边缘部分提供连通性和交换。

4. 传输数据的3种交换方式
1.电路交换：类似打电话，建立连接 → 通信 → 释放连接。通信时一直占着一条线路，就算暂时没传数据也占资源，所以资源利用率低。
2.报文交换：整个报文一起传。每到一个中间节点，都要先把整个报文收完、存下来，再转发到下一个节点。优点是不需要提前占一条线路，缺点是报文大时等待久、占存储空间大。
3.分组交换：把一个大报文切成很多小分组，每个分组单独存储转发。路由器收到一个完整分组就可以继续转发，不用等整个报文收完，多个用户还能共享链路。互联网主要使用分组交换。
3种方式区别：电路交换=先占路再传；报文交换=整个大报文收完再传；分组交换=切成小块，一个分组一个分组传。

5. 计算机网络的分类
1.按分布范围：广域网、城域网、局域网、个人区域网。
广域网：范围很大，可以跨地区、国家。
城域网：大致一个城市范围。
局域网：范围较小，例如学校、公司内部。
个人区域网：个人身边很小的范围。
2.按使用者：公用网、专用网。
公用网：给公众使用。
专用网：某个单位、组织自己使用。
3.按交换技术：电路交换、报文交换、分组交换。
4.按拓扑结构：总线型、星型、环型、网状型。
总线型：大家接在一条主线上。
星型：所有设备连到一个中心。
环型：设备首尾相连形成一个环。
网状型：节点之间有很多连接，像一张网。

6. 计算机网络性能
 速率：单位时间传输的数据量，单位b/s。1kb/s=10^3b/s，1Mb/s=10^6b/s，1Gb/s=10^9b/s；1B=8bit，存储容量中1KB=1024B。
 带宽：链路所能达到的最高数据传输速率，单位也是b/s。
 吞吐量：单位时间内实际传输的数据量，一般小于等于带宽。
 时延分为发送时延、传播时延、处理时延、排队时延。
 发送时延=数据长度/发送速率。
 传播时延=链路长度/传播速度。
 总时延=发送时延+传播时延+处理时延+排队时延。
 时延带宽积=传播时延×带宽，表示链路中正在传播的数据量。
 RTT：往返时间，从发送方发送数据开始，到收到对方返回信息所经历的时间。
 利用率：网络或链路被使用的程度，利用率太高时排队时延会明显增大。
 注意单位：链路长度通常用m；光纤中约2×10^8m/s指的是传播速度，不是发送速率。发送速率看b/s，传播速度看m/s。
 注意区分bit和Byte：1B=8b；b/s表示速率，B、KB、MB、GB表示存储容量。网络速率中的k、M、G按10^3进位，存储容量中的KB、MB、GB通常按1024进位。

7. 计算机网络体系结构
协议：通信双方必须共同遵守的规则，主要包括语法、语义和同步。语法规定“数据长什么样”，语义规定“这些内容什么意思”，同步规定“什么时候做什么、先后顺序怎样”。
服务：下层为紧邻的上层提供服务，上层使用下层提供的服务；同一层通信双方遵守相应协议。
常见有3种体系结构：OSI七层参考模型、TCP/IP四层模型、五层参考模型。
OSI七层：物理层 → 数据链路层 → 网络层 → 传输层 → 会话层 → 表示层 → 应用层。OSI是ISO提出的法律上的国际标准，但实际互联网没有采用它作为主要体系结构。
TCP/IP四层：网络接口层 → 网际层 → 运输层 → 应用层。TCP/IP在实际互联网中广泛使用，是事实上的国际标准。
五层参考模型：物理层 → 数据链路层 → 网络层 → 运输层 → 应用层，主要用于教学。可以理解成把TCP/IP的网络接口层拆成物理层和数据链路层，同时把OSI上面的应用层、表示层、会话层合并成应用层。
三种模型主要区别就是层数和部分层的合并方式不同，核心分层思想相同。
应用层：直接为用户和应用程序提供网络服务，常见协议HTTP、FTP、SMTP、DNS，协议数据单元一般叫报文。
运输层：负责两个主机中进程与进程之间的通信，可以提供可靠传输、流量控制等，常见协议TCP、UDP，协议数据单元通常叫报文段（TCP）或用户数据报（UDP）。
网络层：负责把分组从源主机送到目的主机，主要进行路由选择和分组转发，常见协议IP、ICMP、OSPF等，协议数据单元叫IP数据报/分组。
数据链路层：负责把网络层传下来的数据组装成帧，在相邻节点之间传输，协议数据单元叫帧。
物理层：负责在实际传输介质上传输0和1的比特流，协议数据单元叫比特。
发送时数据从上到下逐层封装，接收时从下到上逐层拆封。
